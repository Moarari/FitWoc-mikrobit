# 🏃‍♂️ Fitness Tracker (Fitwatch)

Moderná webová aplikácia slúžiaca ako osobný fitness tracker, ktorý komunikuje s hardvérom **BBC Micro:bit**. Aplikácia prehľadne zobrazuje tvoju dennú aktivitu a motivuje ťa prekonávať vlastné hranice.

![Ukážka aplikácie](image_8aa716.png) *(Poznámka: Ak máš obrázok v repozitári, uisti sa, že názov súboru sedí)*

---

## 🚀 Hlavné funkcie

Aplikácia dokáže v reálnom čase spracovávať dáta a monitorovať nasledovné hodnoty:

* **Pripájať Micro:bit:** Jednoduché prepojenie hardvéru s webovým rozhraním pomocou jedného tlačidla.
* **Aktuálne hodnoty:** * 👣 **Kroky:** Počítanie krokov v reálnom čase.
    * 🔥 **Kalórie:** Výpočet spálených kalórií v `kcal`.
    * 📏 **Vzdialenosť:** Prejdená vzdialenosť prepočítaná na metre `m`.
* **Osobný rekord (Personal Best):** Aplikácia si pamätá tvoje doterajšie maximá:
    * 🏆 Najviac krokov
    * 🔥 Najviac spálených kalórií
    * 🛣️ Najväčšia dosiahnutá vzdialenosť

---

## 🛠️ Použité technológie

* **Frontend:** HTML, CSS (štýlované do moderného a čistého glassmorfizmu)
* **Hardvér:** BBC Micro:bit
* **Komunikácia:** WebUSB / Web Bluetooth API (pre prenos dát z Micro:bitu)
